## 3. Structured Data (JSON-LD) Strategy
1. **Root (`/`)**: `Person` entity graph linking social profiles (GitHub, LinkedIn), verified role, address, jobTitle, and alumniOf.
2. **WebSite**: Sitelinks Searchbox and WebSite metadata.
3. **BreadcrumbList**: Applied on all `/skills/*` and `/projects/*` routes to render rich breadcrumb trails in SERPs.
4. **FAQPage**: Applied on skill detail pages where 4 contextual, verified FAQs exist.
5. **CreativeWork / SoftwareApplication**: Applied on project case studies documenting architecture, repository URL, and technologies.

## 4. Crawl Budget & Indexation Governance
- Dynamic `sitemap.xml` generated via Next.js `sitemap.js`.
- Clean `robots.txt` generated via Next.js `robots.js`, explicitly disallowing `/api/*` internal routes.
- Self-referential canonical tags on all indexable URLs preventing parameter duplication.
- HTTP 200 responses with zero redirect chains across internal links.
